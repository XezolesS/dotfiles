# XezolesS/dotfiles

The dotfiles are managed with `chezmoi`.

Will add more instruction.

## Requirements

- [`chezmoi`](https://github.com/twpayne/chezmoi)

```bash
sudo pacman -S chezmoi
```

## System

- `Arch Linux`

- `KDE Plasma`
- `hyprland`
- `i3`

- `NetworkManager` for network management.
- `dns-over-https` for DNS-over-HTTPS feature.
- [`fnott`](https://codeberg.org/dnkl/fnott) for a notification daemon.
